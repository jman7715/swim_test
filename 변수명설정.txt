// 1. 선수가 설정한 값 (또는 폼을 통해 전달받은 값)
const targetAge = 53;  // 기준 나이
const ageRange = 5;    // 위아래 5세 범위

// 2. 최소/최대 나이 계산
const minAge = targetAge - ageRange; // 48
const maxAge = targetAge + ageRange; // 58

// 3. 전체 선수 명부에서 해당 나이 범위에 속하는 선수들만 골라내기 (Filtering)
const filteredParticipants = allParticipants.filter(player => {
  return player.age >= minAge && player.age <= maxAge;
});

console.log(`${minAge}세부터 ${maxAge}세까지의 비교 대상 선수를 필터링했습니다.`);




📁 최종 파일 구성 및 역할
server.js (메인 홈 화면 - 최상위 진입점)
접수 기간(시작일~마감일) 설정값을 바탕으로 각 버튼 활성화/비활성화 제어
접수 기간: [접수하기], [등록상황 확인 및 수정] 활성화 / [배번 공지] 비활성화
접수 마감 후: [접수하기], [등록상황 확인 및 수정] 비활성화 / [배번 공지] 활성화


ticket.js (선수용 - 접수 신청)
참가자 정보 입력 폼, 입력값 검증(하이픈 자동변환, 자릿수 확인 등)
swimmers.xlsx 파일에 데이터 Persistence(저장) 처리


player_check.js (선수용 - 등록상황 확인 및 셀프 수정)
이름 + 연락처4(연락처 뒤 4자리) 입력 후 조회
희망경기, 예상기록, 기념품 등 선수 본인이 직접 수정할 수 있는 항목 변경 제공


player_bib.js (선수용 - 배번 및 레인/조 공지)
접수 마감 후, 이름 + 연락처4 입력하여 본인의 배정 조/레인/경기 시간 조회


admin.js (관리자 전용 대시보드)
접수 통계: 현재 총 접수 인원 및 부서/경기별 인원 실시간 카운트
전체 명단 조회/검색: 이름, 소속, 참가부서 등으로 특정 선수 빠른 검색
참가비 원클릭 관리: 리스트에서 '미미입금납 / 완납' 클릭 시 즉시 엑셀 데이터에 반영
대리 수정: 선수 전화 문의 시 희망경기, 예상기록, 기념품 등 대리 수정 (※ 단, 이름/주민번호 오타 수정은 데이터 안전을 위해 원본 엑셀 직접 수정 권장)
